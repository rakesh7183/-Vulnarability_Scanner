VulScanX is a Python-based vulnerability scanning tool designed to detect security weaknesses across both network infrastructure and web applications. It combines multiple scanning techniques into a single lightweight and easy-to-use system, making it ideal for cybersecurity learners and developers.
🚀 Features
🔍 Port Scanning – Identifies open ports and active services
🧠 Service Fingerprinting – Detects running services and versions
🌐 Web Vulnerability Detection – Tests for SQL Injection (SQLi) and XSS
📂 Directory Discovery – Finds hidden paths and endpoints
🔒 SSL & Security Analysis – Checks certificates and configurations
📊 Detailed Reporting – Generates structured reports with severity levels and fixes
